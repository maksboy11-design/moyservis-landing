# ADR-001: Hybrid Architecture

**Статус:** Accepted  
**Дата:** 2026-07-29  
**Контекст:** Нужна масштабируемая структура для one-page landing с сильной DS и формой заявок.

**Решение:** Hybrid = Atomic/CDD UI + Section/Feature-based product blocks + thin domain.

**Последствия:** Чёткие слои; новые секции без переписывания ui; lead изолирован в feature.
