# Product Analysis Report

**Проект:** МойСервис  
**Источник:** PRD Том 1–2 · User query · Design refs

## 1. Product Vision

### Главная цель продукта
Создать production-ready одностраничный лендинг сервисного центра по ремонту цифровой техники, который:
- последовательно снижает воспринимаемый риск;
- формирует устойчивое доверие;
- приводит к заявке / звонку / мессенджеру / визиту;
- одновременно служит портфолио-кейсом Senior/Lead уровня.

### Продуктовая стратегия
**Сначала доверие → потом действие.**  
Не продавать ремонт агрессивно, а управлять восприятием риска через доказательную коммуникацию.

Стратегическая гипотеза (PRD): если сайт отвечает на страхи, показывает доказательства компетентности и делает процесс прозрачным — конверсия растёт без агрессивного маркетинга.

### Бизнес-цели (иерархия)

| P | Цель |
|---|------|
| P1 | Вызвать доверие |
| P1 | Получить заявку |
| P2 | Обратный звонок / VK / MAX |
| P3 | Визит в сервисный центр |
| P4 | Сильный портфолио-кейс |

### UX-цели
- Снизить тревожность
- Минимизировать когнитивную нагрузку
- Быстро ответить на ключевые вопросы
- Создать ощущение профессионализма
- Сделать обращение максимально простым

### KPI / Success Criteria (ориентиры концепта)
- Пользователь понимает услуги, процесс, сроки, гарантии
- Не испытывает тревоги по стоимости
- Готов связаться
- Просматривает trust-блоки (гарантия, процесс, мастера, отзывы)
- Низкий bounce после Hero
- Высокий CTR по CTA

### Ограничения
- Одностраничный лендинг (не multi-page портал)
- Город: Краснодар
- Бренд вымышленный, но данные/тексты/визуал — максимально реалистичные
- Не конкурировать «самой низкой ценой»
- Не использовать glassmorphism вопреки референсам
- Не изобретать новый визуальный стиль

## 2. Value Proposition

**UVP:**  
«Опытные и честные мастера, оригинальные комплектующие, фиксированная стоимость после согласования и большинство ремонтов за 1–2 рабочих дня.»

**Brand Promise:**  
«Мы относимся к вашей технике так же внимательно, как к собственной.»

**Эмоциональный критерий успеха:**  
«Похоже, этим людям действительно можно доверить моё устройство.»

## 3. Positioning

| Не конкурируем | Конкурируем |
|----------------|-------------|
| Минимальная цена | Прозрачность |
| Акции / скидки | Доверие |
| Громкие обещания | Экспертность + UX |

Ниша: между «эконом-мастерской» и «авторизованным премиум-сервисом» — независимый сервис с уровнем коммуникации как у Apple/Dell/ASUS Service.

## 4. Product Principles (обязательные)

1. **Transparency First** — показывать процесс  
2. **Explain Before Asking** — не просить заявку раньше объяснения  
3. **Proof Over Promises** — доказательство к каждому тезису  
4. **Calm Interface** — успокаивать, не давить  
5. **Progressive Trust** — каждый экран усиливает уверенность  
6. **Less Friction** — минимум шагов до контакта  
7. **Human-Centered Communication** — тон специалистов, не рекламы  

Приоритет спорных решений:  
Доверие → простота CTA → понятность → реалистичность → выразительность → анимации.

## 5. Scope продукта (MVP production landing)

### In scope
- Полный one-page лендинг по IA
- Адаптив Desktop / Tablet / Mobile
- Формы заявки и обратного звонка
- Каналы: телефон, VK, MAX, карта/маршрут
- Design System на токенах
- A11y, SEO, performance, security baseline
- Аналитика событий (готовность к подключению)

### Out of scope (v1)
- Полноценная CMS-админка (опционально later)
- Личный кабинет клиента
- Онлайн-оплата
- Трекинг статуса ремонта в реальном времени
- Multi-language

## 6. Риски продукта и митигация

| Риск | Митигация |
|------|-----------|
| Перегрузка секциями | Одна секция = один вопрос |
| «Красиво, но неубедительно» | Proof-блоки с фото/цифрами |
| Ранний CTA → давление | CTA после/параллельно trust, без hero-спама |
| Несоответствие рефам | Design QA по скринам на каждом PR |
| Техдолг | Токены + CDD с первого коммита |
